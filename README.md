# Galerie de Goma - Projet Cloud Computing

**Étudiant :** Kambale Mughere Jérémie
**Classe :** L3 IAGE
**Projet :** Galerie d'images hébergées sur Cloudinary

---

## 🎯 Objectif du projet
Présenter la ville de Goma à travers 3 images hébergées dans le Cloud avec Cloudinary.
Les images sont cliquables : en cliquant dessus, on ouvre l'image originale sur Cloudinary.

## 🖼️ La Galerie

### 1. Le Lac Kivu
Le Lac Kivu, un des plus beaux lacs de Goma. Un lieu de détente, de pêche et de beauté naturelle au bord de notre ville.
- Lien Cloudinary : https://res.cloudinary.com/tvdmlnqa/image/upload/v1794376346/Screenshot_20261111-074408.png.jpg

### 2. Le Volcan Nyiragongo
Le Volcan Nyiragongo, le symbole de Goma. Célèbre dans le monde entier pour son lac de lave, il fait la fierté de notre région.
- Lien Cloudinary : https://res.cloudinary.com/tvdmlnqa/image/upload/v1794376420/Screenshot_20261111-074529.png.jpg

### 3. La Ville de Goma
Vue aérienne de la ville de Goma, une ville dynamique, accueillante et pleine de vie au Nord-Kivu.
- Lien Cloudinary : https://res.cloudinary.com/tvdmlnqa/image/upload/v1794376494/Screenshot_20261111-074450.png.jpg
